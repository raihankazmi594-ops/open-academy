# The Open Academy — Philosophy Study Website

A free, self-paced philosophy learning website with an expanded 24-week university-level independent study curriculum.

## Run it
Open `index.html` in a browser. Select **Curriculum** to view the full programme. No build tools or dependencies are needed.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `philosophy-study`).
2. Upload `index.html`, `curriculum.html`, `.nojekyll`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will show your public website URL when deployment finishes.

## What's included
- Home page with six introductory interactive lessons.
- 24-week university-level independent philosophy syllabus.
- Weekly reading and assignment guidance.
- Four term assessments and six major writing milestones.
- Essay rubric and free academic reading links.

## Notes
- Lesson completion and journal notes are saved in the visitor's browser using local storage.
- This is a static site and does not need a server, database, or paid hosting.
- Progress and notes do not automatically sync between devices.
- The curriculum is not an accredited degree or formal qualification.
